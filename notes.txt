WirelessPy
WirelessPy is an open-source, modular device management platform built with Python, designed to simplify configuring, 
controlling, and managing devices through a modern web interface. The project emphasizes clean architecture, scalability, 
and extensibility, making it easy to add new tools and modules as it evolves.
WirelessPy communicates with system-level tools and services through a structured backend while providing an intuitive 
frontend for users. Its modular architecture separates routing, business logic, and system operations, creating a maintainable 
codebase that can grow without major refactoring.

WirelessPy v2
WirelessPy v2 focuses on Android device management through ADB, providing a stable foundation for future expansion. 
It includes a web dashboard, REST API, logging, authentication, and database integration while maintaining a clean, 
modular architecture.

WirelessPy v3 (Vision)
WirelessPy v3 expands beyond Android into a multi-platform device management platform.
Instead of focusing solely on ADB, it aims to provide a unified environment for managing and interacting 
with different operating systems and devices through independent modules.

--- Flow ---
User Interaction (Button / Input)
        ↓
Frontend JavaScript (fetch API)
        ↓
FastAPI Route Handler
        ↓
Router Layer (routes/api.py or routes/web.py)
        ↓
Core Logic Layer (core/, modules/)
        ↓
System Layer (ADB / subprocess / OS)
        ↓
Process Result Returned
        ↓
JSON Response
        ↓
Frontend Updates DOM/UI
